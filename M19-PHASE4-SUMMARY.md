#### sitemap.ts
**Purpose:** Help search engines discover and index pages efficiently

**Pages Included:**
1. **Homepage** (/)
   - Priority: 1.0 (highest)
   - Change frequency: hourly
   - Reason: Wait time data updates frequently

2. **Methods** (/methods)
   - Priority: 0.9
   - Change frequency: weekly
   - Reason: Methodology documentation (occasional updates)

3. **Analytics** (/analytics)
   - Priority: 0.8

   - Reason: Aggregate data updated daily

4. **Data Quality** (/data-quality)
   - Priority: 0.8
   - Change frequency: daily
   - Reason: Quality metrics updated daily

5. **FAQ** (/faq)
   - Priority: 0.7
   - Change frequency: monthly

6. **Privacy Policy** (/privacy)
   - Priority: 0.5

   - Priority: 0.5

   - Reason: Legal page, rare updates

## Architecture Notes

### Next.js 14 Special Files

Both `robots.ts` and `sitemap.ts` are special route handlers:
- Placed in `app/` directory (not `app/api/`)
- Return specific types (`MetadataRoute.Robots`, `MetadataRoute.Sitemap`)
- Automatically served at `/robots.txt` and `/sitemap.xml`
- Generated on each request (dynamic)

### SEO Best Practices

**robots.txt:**
- User-agent wildcards for broad rules
- Specific bot directives for AI training opt-out
- Sitemap reference for crawlers
- Host declaration for canonical URL

**sitemap.xml:**
- XML format automatically generated
- lastModified for cache invalidation
- changeFrequency for crawl scheduling
- priority for relative importance

### AI Training Opt-Out

The robots.txt includes explicit blocks for:
- **GPTBot** - OpenAI's web crawler for training
- **CCBot** - Common Crawl (used by many AI companies)
- **Google-Extended** - Google's AI training crawler
- **Others** - Anthropic, Perplexity, ChatGPT browsing

**Rationale:**
- Protects original scholarship
- Maintains attribution control
- Prevents methodology dilution in AI responses
- Demonstrates data governance awareness

This is particularly important for a medical school portfolio, showing:
- Understanding of intellectual property
- Awareness of AI ethics
- Control over research dissemination
