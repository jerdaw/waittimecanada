📊 Recorded-Tag Screening Criteria

All five recorded ontology tags must match for the tag-alignment screen to pass:

comparable = (
    measurement_a.metric_family == measurement_b.metric_family AND
    measurement_a.start_event == measurement_b.start_event AND
    measurement_a.end_event == measurement_b.end_event AND
    measurement_a.statistic_type == measurement_b.statistic_type
    AND measurement_a.patient_scope == measurement_b.patient_scope
)

Matching tags are necessary but do not prove source methods are identical or a scientific comparison is valid. Review source definitions and limitations. Unknown patient scope never counts as a match.
